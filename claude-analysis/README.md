## 边界

- 私有部署不等于没有崩溃、重复请求、并发取消或租户数据串线风险。
- 不预设删 Kafka、改共享 JSONL、缩减多 Worker/多 Lane 能力。
- 不把“没有调用者的遗留”与“承担正确性职责但代码偏多”混为一谈。
- 本次不宣称已重跑真实模型、Cube KVM、全量测试或企业规模容量验收。
- 不提交 Claude 原始会话、凭据、用户数据；报告仅保留审查结论及源码证据。
